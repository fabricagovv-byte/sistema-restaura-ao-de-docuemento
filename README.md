# Painel Nacional de Licitações — versão para usar fora do Claude

| Arquivo | O que é |
|---|---|
| `index.html` | O painel inteiro num arquivo só (dados da coleta de 19/11/2026 06h46). Abre em qualquer navegador. |
| `calendario-foco.ics` | Agenda com o prazo de todas as abertas do seu foco (fábrica, desenvolvimento, manutenção, sustentação, digitalização), com link do PNCP e aviso 2 dias antes. |
| `calendario-licitacoes-premiadas.ics` | Agenda das premiadas (nota 55 ou mais). |
| `calendario-licitacoes-premiadas.csv` | As mesmas premiadas em planilha, com os links. |

Fora do Claude, o CRM, os marcadores e as análises ficam guardados só no navegador em que você usar (não sincronizam
entre aparelhos), e o botão de análise com IA não funciona. Os dados não se atualizam sozinhos: cada nova coleta
precisa gerar e publicar o arquivo de novo.

Assinar a agenda no Google Agenda: Outras agendas → + → Do URL → cole o endereço "raw" do `.ics`.
